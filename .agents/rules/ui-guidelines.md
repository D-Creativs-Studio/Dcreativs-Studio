# UI / UX Styling Guidelines & Prohibited Tropes

## Strict Prohibitions
- **NEVER use generic AI/SaaS-style pill badges with status dots/beacons**:
  - Do NOT create pill-shaped tag containers with a dot/indicator and uppercase monospace or tracking-widest text (e.g. `[ • INITIATE A COLLABORATION ]`, `[ • STATUS ]`, `[ • AI POWERED ]`, `[ • AVAILABLE FOR WORK ]`).
  - The user strongly dislikes this design trope and never wants to see it on any projects.
- **Maintain Clean, High-End Editorial Typography**:
  - Let headlines and bold typography speak for themselves without cheesy eyebrow pill badges or flashing radar dots.
  - Rely on strong typographic hierarchy, negative space, and premium layout structure.
