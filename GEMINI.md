# Project Instructions & Preferences

## UI / UX Styling Guidelines & Prohibitions
- **NEVER use generic pill badges with status dots/beacons**:
  - Do NOT create pill-shaped badge containers featuring a pulsing dot/beacon alongside uppercase monospace or letter-spaced text (e.g. `[ • INITIATE A COLLABORATION ]`, `[ • STATUS ]`, `[ • AI POWERED ]`, `[ • AVAILABLE FOR WORK ]`).
  - The user explicitly dislikes this design trope and never wants to see it on any projects.
- **NO Emojis**:
  - NEVER use emojis in the project UI, headings, body copy, badges, success states, or buttons (e.g., no 🚀, 👆, 🔥, ✨, etc.).
  - Rely on clean typography, editorial hierarchy, or professional SVG / Lucide icons instead.
- **Typography & Layout**:
  - Maintain clean, high-end editorial aesthetics.
  - Let headlines and bold typography lead without cluttering with cheesy eyebrow pills or flashing radar dots.
